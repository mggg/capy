# data/shared

All data produced or consumed by the core pipeline. Everything here is gitignored (except small source files in `raw/study_area_sources/`) and must be regenerated by running `bash scripts/reproduce.sh`.

| Subfolder | Contents |
|---|---|
| `raw/` | Original source files downloaded from the Census API, TIGER FTP, and IPUMS/NHGIS. |
| `processed/` | Intermediate files produced by the preprocessing steps (attributed shapefiles, study area boundaries, clipped geographies, dual graphs). |
| `outputs/` | Final pipeline outputs for each run configuration: metrics CSVs, figures, and LaTeX tables. |
