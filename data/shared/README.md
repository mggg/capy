# data/shared

All data produced or consumed by the core pipeline.

| Subfolder | Contents |
|---|---|
| `raw/` | Original source files downloaded from the Census API and IPUMS/NHGIS. |
| `processed/` | Intermediate files produced by the preprocessing steps (attributed geodata, study area boundaries, clipped geographies, dual graphs). |
| `outputs/` | Final pipeline outputs for each run configuration: metrics CSVs, figures, and LaTeX tables. |
