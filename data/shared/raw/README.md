# data/shared/raw

Raw source files downloaded by `capy_core/download/`. Nothing here is generated by the pipeline itself; all files are fetched from external sources and should not be edited.

| Subfolder | Contents |
|---|---|
| `geographies/census_{year}_{level}/` | TIGER/Line shapefiles (2000-2020) downloaded from the Census FTP, one folder per year × level combination. |
| `geographies/ipums_geography_extracts/{year}/{level}/` | NHGIS shapefile extracts (1980-1990) downloaded via the IPUMS API. |
| `population/census_{year}_{level}.csv` | Decennial census race/ethnicity counts (2000-2020) fetched from the Census API. |
| `population/ipums_population_extracts/{year}/` | NHGIS population table extracts (1980-1990) downloaded via the IPUMS API. |
| `study_area_sources/` | CBSA delineation `.xls` files from the Census Bureau (e.g. `list1_march_2020.xls`); the only files in `raw/` that are committed to git. |
