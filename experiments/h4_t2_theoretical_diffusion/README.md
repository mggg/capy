This folder contains scripts and figures on the topic of theoretical diffusion. Folders:

1. `scripts/` contains `plot_clustering_figure.py` that creates a figure with theoretical grids, showing metrics calcualted on grid examples with low, medium, and high clustering.
2. `utils/` contains a helper scripts with colors and other viz details to be used in this folder for visualization.
3. `figures/` is a folder for figures.
